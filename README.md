# privacy-policies

Privacy policy pages for Billog Studio's published apps, served via GitHub Pages.

Each app gets its own subdirectory (e.g. `skyscrapers/`), served at
`https://billog-studio.github.io/privacy-policies/<app>/` - that URL is what
goes into each app's store listing (Google Play Console's "Privacy policy"
field, App Store Connect, etc).

To add a new app's policy, create a new subdirectory with an `index.html`.
